# E-commerce Product Listing

A React e-commerce product listing app with filtering, sorting, pagination, and cart state using Zustand.

## Features

- Fetch products from API
- Category filter
- Maximum price filter
- Sort by price
- Pagination
- Add to cart
- Increase/decrease quantity
- Remove from cart
- Cart item count
- Total price calculation
- Responsive product grid

## Tech Stack

- React
- Vite
- JavaScript
- Tailwind CSS
- Zustand
- Fake Store API
- Bun

## Run Locally

```bash
bun install
bun run dev
